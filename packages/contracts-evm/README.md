# WaifuFun EVM Contracts

This package restores the historical EVM contracts that originally lived under
`packages/evm-contracts` on `origin/evm-contracts` at commit
`dfe748df0fc4d5a4a095adde01de7e97faa105eb`.

The source in that branch used `AutoFun*` names. It has been carried over here
as `WaifuFun*` so it matches the ABI and RPC naming already committed in this
repository.
