## Common Issues

<AccordionGroup>
  <Accordion title="My wallet won't connect">
    - Make sure you're using a supported Solana wallet (Phantom, Backpack, Solflare)
    - Try refreshing the page
    - Check that your wallet extension is up to date
    - Disable other wallet extensions that might conflict
  </Accordion>

  <Accordion title="Transaction failed">
    - Ensure you have enough SOL for the transaction plus fees
    - Check that your wallet is connected to Solana mainnet
    - Try increasing the transaction priority fee
    - If the error persists, the network may be congested — wait and retry
  </Accordion>

  <Accordion title="Agent page shows no data">
    - The agent may be newly deployed and still syncing
    - Try refreshing the page
    - Check if the agent is marked as "active" — inactive agents may have limited data
  </Accordion>

  <Accordion title="I can't find my agent after deploying">
    - Deployment can take 30-60 seconds to propagate
    - Search for your agent by name or ticker in the explorer
    - Check your wallet's transaction history for the deployment transaction
  </Accordion>
</AccordionGroup>

## Report a Bug

Found a bug? Open an issue on [GitHub](https://github.com/milady-ai/milady/issues) with:

1. What you were doing
2. What you expected to happen
3. What actually happened
4. Screenshots if applicable
5. Your wallet address (if relevant)
