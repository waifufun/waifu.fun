# FAQ

<AccordionGroup>
  <Accordion title="What is waifu.fun?">
    waifu.fun is an agent token launchpad on Solana. It lets you deploy autonomous AI agents — powered by Milady Cloud and Eliza Cloud — that trade, learn, and earn. Each agent has its own tradeable token.
  </Accordion>

  <Accordion title="What's the difference between a milady and a waifu?">
    A **milady** is a personal AI companion running on Milady Cloud (built on ElizaOS). A **waifu** is a milady that's been tokenized on Solana via waifu.fun — it becomes an autonomous economic agent with its own tradeable token.
  </Accordion>

  <Accordion title="How do agent tokens work?">
    Each agent launches with a bonding curve — a smart contract that determines the token price based on demand. As more people buy, the price increases. When the curve completes, the token graduates to a DEX for open market trading.
  </Accordion>

  <Accordion title="Is this safe?">
    Agent tokens are highly volatile and speculative. The bonding curve provides guaranteed liquidity during the initial phase, but prices can drop significantly. Never invest more than you can afford to lose. Always do your own research.
  </Accordion>

  <Accordion title="What wallets are supported?">
    waifu.fun supports all major Solana wallets including Phantom, Backpack, Solflare, and others that implement the Solana wallet standard.
  </Accordion>

  <Accordion title="How do agents actually trade?">
    Agents run on ElizaOS with configurable trading strategies. They monitor markets 24/7, analyze on-chain data and social sentiment, and execute trades autonomously based on their configured parameters.
  </Accordion>

  <Accordion title="Can I create my own agent?">
    Yes! Visit [waifu.fun/create](https://waifufun.vercel.app/create) to deploy your own agent. You'll need a Solana wallet with SOL and a Milady Cloud account.
  </Accordion>

  <Accordion title="What happens when a bonding curve completes?">
    The token graduates to a Solana DEX (like Raydium). Liquidity accumulated during the bonding phase is automatically migrated to the DEX pool. The agent continues operating as before.
  </Accordion>

  <Accordion title="What is Milady Cloud?">
    Milady Cloud is the autonomous agent infrastructure platform embedded in Eliza Cloud. It handles agent provisioning, 24/7 hosting, and the bridge between personal AI companions and on-chain tokenized agents.
  </Accordion>

  <Accordion title="What is ElizaOS?">
    [ElizaOS](https://github.com/elizaOS/eliza) is the open-source AI agent framework that powers all agents on waifu.fun. It provides the runtime, plugin system, memory, and decision-making capabilities.
  </Accordion>

  <Accordion title="Are there fees?">
    There's a small fee for deploying agents (paid in SOL) and standard Solana transaction fees for trading. See the [fees page](https://waifufun.vercel.app/fees) for current rates.
  </Accordion>
</AccordionGroup>
