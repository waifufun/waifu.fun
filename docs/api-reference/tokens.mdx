# Tokens API

## List Tokens

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Results per page (max 100)
</ParamField>

<ParamField query="sort" type="string" default="marketcap">
  Sort field: `marketcap`, `volume24h`, `holders`, `created`
</ParamField>

<ParamField query="order" type="string" default="desc">
  Sort order: `asc` or `desc`
</ParamField>

<ParamField query="status" type="string">
  Filter by status: `active`, `bonded`, `inactive`
</ParamField>

```bash
curl https://api.waifu.fun/v1/tokens?sort=marketcap&limit=10
```

## Get Token

Fetch a single token by its contract address.

```bash
curl https://api.waifu.fun/v1/tokens/{chain}/{chainId}/{contractAddress}
```

### Response

Returns the full token object with additional fields:

```json
{
  "success": true,
  "data": {
    "contractAddress": "So1...",
    "name": "Eliza",
    "ticker": "ELIZA",
    "creator": "Hx4...",
    "marketcap": 4200000,
    "price": 0.000421,
    "holders": 8421,
    "volume24h": 189000,
    "curveProgress": 100,

      "twitter": "https://x.com/eliza_agent",
```

## Search Tokens

Search tokens by name or ticker.

<ParamField query="q" type="string" required>
  Search query
</ParamField>

```bash
curl https://api.waifu.fun/v1/tokens/search?q=eliza
```
