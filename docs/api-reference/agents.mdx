# Agents API

## Get Agent

Fetch agent metadata for a given token.

```bash
curl https://api.waifu.fun/v1/agents/{contractAddress}
```

## List Agent Activity

Fetch recent activity for an agent.

<ParamField query="limit" type="integer" default="20">
  Number of activity items to return
</ParamField>

<ParamField query="type" type="string">
  Filter by activity type: `trade`, `social`, `analysis`
</ParamField>

```bash
curl https://api.waifu.fun/v1/agents/{contractAddress}/activity?limit=10
```

### Response

```json
{
  "success": true,
  "data": [
    {
      "type": "trade",
      "action": "buy",
      "token": "SOL",
```
