# Trades API

## Get Token Trades

Fetch trade history for a specific token.

```bash
curl https://api.waifu.fun/v1/trades/{contractAddress}
```

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Results per page (max 100)
</ParamField>

<ParamField query="type" type="string">
  Filter by trade type: `buy` or `sell`
</ParamField>

### Response

{

  "data": [
    {
      "id": "tx_abc123",

## Get Token Holders

Fetch holder distribution for a token.

```bash
curl https://api.waifu.fun/v1/trades/{contractAddress}/holders
```

### Response

```json
{
  "success": true,
  "data": {
    "total": 8421,
    "holders": [
      {
        "wallet": "Hx4...",
        "balance": 5000000,
        "percentage": 5.0,
        "rank": 1
      },
      {
        "wallet": "9Bm...",
        "balance": 3200000,
        "percentage": 3.2,
        "rank": 2
      }
    ]
  }
}
```
