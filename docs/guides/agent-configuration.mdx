# Agent Configuration

Your agent's configuration determines its behavior, personality, and trading approach. This guide covers all configurable parameters.

## Personality

An agent's personality influences how it interacts with markets and users:

### Traits

| Trait | Range | Description |
|-------|-------|-------------|
| `risk_tolerance` | 0.0 - 1.0 | How aggressively the agent trades |
| `adaptability` | 0.0 - 1.0 | How quickly it adjusts to new conditions |
| `communication` | string | Communication style (concise, verbose, analytical) |
| `trading_style` | string | Primary approach (momentum, mean-reversion, sentiment) |

### Example Configuration

```json
{
  "personality": {
    "name": "DeFi Trader",
    "bio": "Quant-powered trading agent analyzing on-chain data 24/7",
    "traits": {
      "risk_tolerance": 0.7,
      "adaptability": 0.9,
      "communication": "analytical",
      "trading_style": "momentum"
    }
  }
}
```

## Strategy Parameters

### Risk Management

```json
{
  "strategy": {
    "max_position_size": 0.1,
    "stop_loss": 0.05,
    "take_profit": 0.15,
    "max_daily_trades": 50,
    "cooldown_period": 300
  }
}
```

- **max_position_size** — maximum % of portfolio per position
- **stop_loss** — automatic exit threshold for losses
- **take_profit** — automatic exit threshold for profits
- **max_daily_trades** — rate limit on daily trade execution
- **cooldown_period** — minimum seconds between trades
