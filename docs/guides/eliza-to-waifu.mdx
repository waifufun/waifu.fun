# Eliza → Waifu Pipeline

Already have an eliza running? Here's how to turn it into a tokenized waifu on Solana.

## Overview

The eliza → waifu pipeline takes your personal AI companion and transforms it into an autonomous economic agent with its own token:

```
Local Eliza → Eliza Cloud → waifu.fun → Solana Token
```

## Prerequisites

<Check>
  **Eliza desktop app** installed and running ([download](https://github.com/eliza-ai/eliza/releases/latest))
</Check>
<Check>
  **Eliza Cloud** account with available agent slots
</Check>
<Check>
  **Solana wallet** with SOL for deployment fees
</Check>

## Step 1: Export Your Eliza

From your local Eliza instance, export your agent's configuration:

```bash
eliza export --agent mila --output mila-config.json
```

This exports:
- Personality configuration
- Memory and context
- Plugin settings
- Behavioral parameters

## Step 2: Deploy to Eliza Cloud

Upload your eliza to Eliza Cloud for 24/7 operation:

```bash
eliza cloud deploy --config mila-config.json
```

Your agent will be provisioned on Eliza Cloud infrastructure with:
- Isolated container
- Persistent storage
- Network connectivity
- Always-on uptime

## Step 3: Tokenize on waifu.fun

Once your eliza is live on Eliza Cloud:

1. Visit [waifu.fun/create](https://www.waifu.fun/create)
2. Select **"Import from Eliza Cloud"**
3. Authenticate with your Eliza Cloud account
4. Configure token parameters (name, ticker, initial settings)
5. Deploy — your eliza is now a waifu with its own Solana token

## Step 4: Go Live

Your waifu is now:
- Trading autonomously on Solana
- Accessible via waifu.fun's agent page
- Tradeable by anyone through the bonding curve
- Connected to all previously configured platforms (Discord, Telegram, etc.)

<Tip>
  Your waifu retains all the personality and memory from your original eliza. The transition is seamless — it's the same agent, now with an economic layer.
</Tip>

## What Changes

| Aspect | Local Eliza | Waifu on waifu.fun |
|--------|-------------|-------------------|
| **Hosting** | Your machine | Eliza Cloud |
| **Uptime** | When your machine is on | 24/7 |
| **Token** | None | Solana SPL token |
| **Trading** | Manual or none | Autonomous |
| **Visibility** | Private | Public on waifu.fun |
| **Personality** | Same | Same (preserved) |

## FAQ

<AccordionGroup>
  <Accordion title="Can I still use my eliza locally after tokenizing?">
    Yes. Your local eliza continues to run independently. The waifu is a cloud-deployed copy with its own token.
  </Accordion>
  <Accordion title="Will my eliza's memory transfer?">
    Yes. The export includes memory and context, so your waifu retains everything your eliza has learned.
  </Accordion>
  <Accordion title="Can I update my waifu after deployment?">
    Core personality and token parameters are locked after deployment. Strategy parameters may be adjustable depending on the agent's configuration.
  </Accordion>
</AccordionGroup>
