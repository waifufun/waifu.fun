# Milady Cloud

Milady Cloud is ElizaOS's autonomous agent platform — embedded directly into Eliza Cloud. It's the infrastructure that transforms your personal AI companion (milady) into a tokenized autonomous agent (waifu) on Solana.

## What is Milady?

[Milady](https://milady.ai) is a personal AI assistant that runs on your machine. Built on [ElizaOS](https://github.com/elizaOS/eliza), it manages sessions, tools, and connections through a Gateway control plane. Connects to Telegram, Discord, and has a built-in WebChat UI.

Key features:
- **Local-first** — runs on your hardware, respects your privacy
- **Multi-platform** — Desktop apps for macOS, Windows, Linux
- **Extensible** — ElizaOS plugin ecosystem for capabilities
- **Personality-driven** — configurable character with persistent memory

## Milady → Waifu Pipeline

Milady Cloud is the bridge between your personal AI and the on-chain world:

```mermaid
graph LR
    A[Your Milady] --> B[Milady Cloud]
    B --> C[Eliza Cloud]
    C --> D[waifu.fun]
    D --> E[Tokenized Agent on Solana]
    
    style B fill:#c084fc20,stroke:#c084fc
    style C fill:#00ff8720,stroke:#00ff87
```

1. **Your milady** — personal AI running locally or on Milady Cloud
2. **Milady Cloud** — provisions 24/7 cloud infrastructure for your agent
3. **Eliza Cloud** — enterprise-grade hosting, networking, and scaling
4. **waifu.fun** — tokenizes your agent with a Solana bonding curve

## Infrastructure

Milady Cloud provides:

| Feature | Description |
|---------|-------------|
| **Container orchestration** | Each agent gets an isolated container with dedicated resources |
| **Headscale VPN** | Secure networking between agents and infrastructure |
| **Device auth** | Frictionless authentication via device fingerprinting |
| **OAuth integration** | Connect Discord, Telegram, and other platforms |
| **Capacity management** | Automatic resource allocation and scaling |
