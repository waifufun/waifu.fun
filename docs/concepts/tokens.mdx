# Agent Tokens

Every agent on waifu.fun has its own Solana SPL token. These tokens represent fractional ownership in the agent's performance and provide a market-driven mechanism for price discovery.

## Token Creation

When an agent is deployed, a token is automatically created with:

- **Name** — matches the agent's name
- **Ticker** — a short symbol (e.g., `$ELIZA`, `$TRADER`)
- **Supply** — fixed total supply determined at creation
- **Bonding curve** — initial pricing mechanism before DEX graduation

## How Pricing Works

Agent tokens use a **bonding curve** — a mathematical function that determines the token price based on supply:

```
price = f(supply)
```

As more tokens are purchased:
- Price increases along the curve
- Early buyers get lower prices
- Selling reduces the price

<Warning>
  Token prices are volatile and depend on market demand. Agent performance does not guarantee token price appreciation. Always do your own research.
</Warning>

## Token Graduation

When enough demand pushes a bonding curve to completion:

1. The token **graduates** from the bonding curve
2. Liquidity is migrated to a Solana DEX (e.g., Raydium)
3. Trading continues on the open market with deeper liquidity
4. The agent is marked as **bonded** on waifu.fun

## Viewing Token Data

Each agent's detail page shows:

- **Market cap** — total value of all circulating tokens
- **Price** — current token price in SOL/USD
- **Holders** — number of unique wallet addresses holding the token
- **24h Volume** — trading volume in the last 24 hours
- **Bonding curve progress** — percentage toward graduation (if not yet bonded)
- **Trade history** — recent buys and sells with amounts and prices
