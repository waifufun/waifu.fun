## Users

bsc degens with multi-wallet setups, agent-curious devs watching what an autonomous strategy actually does on-chain, traders eyeballing positions across hyperliquid + pancake + spot, the occasional patron checking on the agent they're sponsoring.

context when they hit the site: usually desktop, second monitor, terminal already open, twitter open, a chart open. mobile happens (sharing a launch link, pulling up a position from the couch) but the page is built for the cockpit not the phone. they're scanning, not reading. numbers first, copy never.

emotional state: focused, slightly degen, dopamine-primed. respect that. don't make them wait. don't make them read a paragraph to find a number.

## Brand Personality

DENSE. LIVE. TPOT.

**DENSE.** cockpit-grade information per square inch. numbers in mono, tabular nums, no whitespace bingo. multiple panels at once, hairlines instead of giant gaps, micro-stats stacked tight. visual_density sits at 4-6 on the design-taste dial. not airy-art-gallery (1-3), not pilot-cockpit-overload (8-10). it's the sweet spot where a trader can scan five data points without a scroll.

**LIVE.** the page breathes. accent-green pulse dots on anything that updates from on-chain. status indicators that actually pulse, not static svg dots. tax stream ticking, positions repricing, recent activity scrolling in. if it's real-time, it should look real-time. if it's stale, say so honestly.

**TPOT.** this part of twitter, terminal-feel, lowercase, dry, sharp. no consumer-crypto sparkle. no animated mascots. no "elevate your degen experience." copy reads like a discord message between two devs at 3am, not like a marketing email. think pump.fun's data grammar with hyperliquid's restraint and linear's polish.

## Aesthetic Direction

dark mode only. single electric-green accent. mono numbers everywhere. panels grouped by hairlines, not by boxy-card-overuse. nothing glows. nothing gradients into purple. nothing centers a hero with a giant H1 that screams.

- **pump.fun** — the live, dense, terminal vibe. we want that energy with cleaner typography.
- **vercel.com / linear.app** — premium tech-minimal restraint. how they handle hierarchy with weight not size.

### Anti-references (do NOT look like)

- launchpads that say "elevate your degen experience" or "unleash agent intelligence."

### Theme

- dark mode only. no light mode toggle. ever.
- single accent: `#00ff87` (electric green). NEVER purple, lila, blue, or any "AI saas" tint.
- off-black bg: `#08080a`. NEVER `#000000`.
- panel bg: `#0b0b0e`. panel-hi (hover/elevated): `#111114`.
- border-soft: `rgba(255, 255, 255, 0.05)`. border-mid: `rgba(255, 255, 255, 0.08)`.
- text: primary `#e8e8eb`, secondary `rgba(255, 255, 255, 0.55)`, tertiary `rgba(255, 255, 255, 0.32)`.
- semantic: positive `#6dd668`, negative `#ff5b5b`, neutral `rgba(255, 255, 255, 0.45)`.

these are not suggestions. they are the THEME_TOKENS in `apps/frontend/src/components/agent-home/wave-t/_primitives.tsx`. if you hardcode a hex that isn't in this list, you're wrong.

## Design Principles

1. **Panels, not Sections.** every data block wraps in `<Panel>` from `wave-t/_primitives.tsx`. no bespoke borders, no `<Section title="..." subtitle="...">` chrome wrappers. one primitive, one look.
2. **Honest empty states.** if there's no data, say so in wave-t grammar: `no data yet · onchain feed quiet`. never `—`, never `N/A`, never a fake zero or fixture leak.
3. **One scope per page.** one `max-w-[1440px]` container, one THEME_TOKENS application at the root. don't nest a second container at a different width and pretend it's a "subsection".
4. **Numbers are mono.** every numeric value uses `font-mono` (jetbrains mono or dm mono via globals.css). labels use sans (satoshi). this is non-negotiable.
5. **Density over whitespace.** this is a cockpit. visual_density 4-6. tight padding inside panels (`p-4 md:p-5`), hairlines between groups, no giant gallery gaps. if you find yourself adding `py-24` you're on the wrong page.

## Visual System

primitives live at `apps/frontend/src/components/agent-home/wave-t/_primitives.tsx`. use them:

- `<Panel>` — the container. `rounded-md`, `border-soft`, `bg-panel`, hover lifts to `border-mid`. that's it.
- `<Label>` — panel header. mono, `text-[10px]`, uppercase, `tracking-[0.22em]`. always `mb-4`. optional `right` slot.
- `<MicroStat label value tone>` — stacked label+value. tone `accent | positive | negative | neutral`. value is `font-mono text-[13px] tabular-nums`.
- `<StatPill tone>` — inline tag. rounded-full, `text-[9px]`, mono, uppercase, `tracking-[0.18em]`.
- `<Pulse tone>` — the live dot. animated ping + solid core. tone `accent | positive | negative`.
- `<Hairline>` — 1px divider. use this instead of `border-t` to group logic inside a panel.
- `<SectionTitle>` — slightly larger label for hero blocks. still mono, still tiny.
- `<TokenIcon>` / `<VenueIcon>` — async-resolved logos with fallback gradient circle. never use lucide user icons or emoji.

typography (already wired in `globals.css`):
- sans: `Satoshi` (regular 400, medium 500)
- mono: `JetBrains Mono` → `DM Mono` → `DMMono` fallback chain
- NO Inter. NO Roboto. NO serif anywhere. ever.

spacing rhythm:
- panel internal padding: `p-4 md:p-5`
- gap between panels: `gap-3` to `gap-4` (cockpit), never `gap-8+`
- hairline groups inside a panel: `space-y-3` or `divide-y` with `border-[var(--border-soft)]`

## Voice & Copy

- lowercase EVERYTHING. exceptions: contract names in CAPS, ticker symbols in CAPS (`SUKI`, `WBNB`), tag labels like `[BNB CHAIN]`.
- never em-dashes. ever. use commas, periods, restructure the sentence.
- banned words: `elevate`, `seamless`, `unleash`, `next-gen`, `revolutionary`, `powerful`, `intuitive`, `delightful`, `harness`, `empower`, `game-changing`.
- yes words: `live`, `ships`, `on-chain`, `open positions`, `tax stream`, `burned`, `graduated`, `presale`, `treasury`, `patron`.
- labels ≤ 3 words. if you can't fit it, the label is wrong, not the column.
- number formatting: `$1.28M` not `$1,284,735`. tooltips can show full precision. percentages: `47.2%` not `47.20%`.
- timestamps: relative in feeds (`2m ago`, `4h ago`), absolute in tooltips (`2026-05-22 04:51 mdt`).
- when there's no data: `no data yet`, `onchain feed quiet`, `waiting on indexer`. honest, lowercase, no apology.
